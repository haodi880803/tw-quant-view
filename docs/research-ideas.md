# 以 tw-quant 為基礎的小型研究實驗提案

這份文件列出可以用「tw-quant 台股紙上交易系統」當實驗平台的研究方向。
每一項都綁定系統實際產生的資料，所以不用另外找資料集就能起步。
最後一節是給你的問題：你的博士領域是哪一個，我再把對應的提案展開成完整的實驗設計。

## 1. 依領域分類的提案

### A. 財務 / 計量經濟

1. **技術訊號的預測力與多重檢定**
   用預測帳本與日 K 回填資料，檢定各技術訊號對 1/5/20 日報酬是否有顯著預測力。
   重點是多重檢定校正：White Reality Check、Hansen SPA、或 bootstrap。
   成果是一張「哪些訊號在校正後仍顯著」的表。

2. **規則式策略 vs 隨機基準的置換檢定**
   把 autopilot 的進出場日期隨機置換，產生零假設分布，看 Reward points 與權益曲線是否顯著優於隨機。
   直接回答「這套系統到底有沒有邊際」。

3. **三大法人籌碼與短期報酬的因果結構**
   以 TWSE 歷史資料回填，做 Granger 因果或面板迴歸，檢驗「外資連賣 N 日」這類訊號的實際資訊含量。

### B. 機器學習 / 預測

4. **挑戰者模型取代零漂移 baseline**
   系統已有 champion/challenger 架構與 walk-forward 評估。
   加入 GBDT 或小型序列模型當挑戰者，用 Diebold-Mariano 檢定比較 MAE 與命中率。
   這是最貼近現有架構、最快能跑出結果的題目。

5. **保形預測（conformal prediction）校準信賴區間**
   目前 ci68/ci95 是用歷史波動度估的。改用 conformal 方法，評估實際覆蓋率是否接近名目覆蓋率。
   題目小、可量化、容易寫成一篇短論文。

### C. 自然語言處理 / LLM

6. **LLM 情緒 vs 詞典情緒的增量資訊**
   同一批新聞標題同時用詞典法與 LLM 標註，比較兩者對次日報酬的解釋力。
   副產品是一個中文金融新聞情緒標註集。

7. **AI 解讀的一致性與自我矛盾偵測**
   快照裡已經出現「評分強力買進」但「預測無方向」的矛盾，AI 解讀也指出了這點。
   可以研究 LLM-as-judge 偵測矛盾的可靠度，以及矛盾與後續報酬的關係。

### D. 控制 / 強化學習 / 最佳化

8. **出場參數的線上多臂實驗**
   影子測試目前是兩臂、固定 60 天。改成 Thompson sampling 的多臂 bandit，線上選擇 stop/trail 參數組。
   探討非定態市場下的樣本效率與後悔值（regret）。

9. **每週調參的過度擬合量化**
   調參每週試 59–63 組，只在樣本外勝過 2% 才採用。
   用 deflated Sharpe ratio 與 CSCV/PBO（probability of backtest overfitting）量化這個流程的過擬合風險。

### E. 決策科學 / 人機互動

10. **AI 解讀如何改變人的決策**
    在檢視頁加入「接受 / 否決建議」的紀錄，研究有無 AI 解讀時決策行為的差異。
    需要你本人當受試者一段時間，或招募少量受試者。

### F. 軟體工程 / 系統可靠性

11. **可重現的量化研究基礎建設**
    系統有狀態雜湊、確定性回放、實驗登錄的雛形。把它整理成方法論：資料血緣、回放、審計軌跡。
    適合寫成技術報告或工具論文。

12. **失效模式與監控設計**
    真實發生過的故障：AI 日報 19 天未產生、OAuth 失效、資料劣化回應、主機整台壞掉。
    用 SRE 的視角設計監控與自癒，做事後分析。

## 2. 共通的實驗設計模板

每個提案都建議照這個格式寫一頁：

1. 假說（一句話）
2. 資料（來源、期間、樣本數）
3. 基準（隨機、零漂移、現任參數）
4. 指標（MAE、命中率、Sharpe、覆蓋率、regret）
5. 檢定（置換、bootstrap、DM 檢定）
6. 預先登錄（先寫下再跑，避免事後挑結果）
